# 牛小七硬件仓开孔流程与通用化方法

## 1. 文档目的

本文说明如何从未开孔的牛小七 STL 生成可安装灵矽 AI 硬件的主体与后置硬件模块，并给出将同一思路迁移到其他 3D 模型时需要保留、替换和新增的能力。

本文是技术流程说明，不是“任意模型已经可以全自动改造”的能力声明。当前牛小七几何 PoC 已经完成确定性布尔、静态碰撞和直线装入采样；视觉语义闭环、真实切片和实物装配仍需继续验证。

## 2. 设计原则

1. **语义判断与几何执行分离**：视觉模型负责理解物体、部件和候选位置；确定性几何程序负责毫米级尺寸、布尔运算和验证。
2. **内部空腔后生成**：先保留完整外观模型，再根据已冻结的硬件档案挖仓，不要求 3D 生成模型在生成阶段猜测内部结构。
3. **开孔不是一次布尔操作**：内部空腔、维护开口、后盖、固定结构和功能孔必须分别设计。
4. **装得下不等于装得进**：除静态包络外，必须检查安装顺序、装入路径、拆出路径、线缆空间和工具空间。
5. **无合法方案时停止**：空间、壁厚、保护区或装入路径不满足时，返回失败原因，不通过牺牲壁厚或破坏外观强行生成。
6. **任何几何修改都产生新版本**：源模型、语义 Mask、硬件档案、打印工艺档案和 Geometry Recipe 必须可追溯。

## 3. 三类需要独立处理的结构

| 结构 | 作用 | 主要约束 |
| --- | --- | --- |
| 内部空腔 | 容纳主板、电池、扬声器和线缆 | 容量、剩余壁厚、硬件间碰撞 |
| 维护开口与后盖 | 允许硬件装入、拆出和维修 | 装入路径、闭合方式、外观接缝、工具空间 |
| 功能孔 | 提供扬声、拾音、充电、按键和指示灯通道 | PCB 接口坐标、声学路径、插头包络、最小特征 |

只从模型中减去一个硬件外包盒，无法同时满足这三类要求。

## 4. 牛小七样板输入

### 4.1 模型坐标与尺度

当前牛小七 V1 使用固定坐标约定：

- 长度单位：毫米；
- 目标高度：`180 mm`；
- `+Y`：向上；
- `+Z`：正脸；
- `-Z`：后脑；
- 原点：脚底中心。

输入模型必须是封闭三角网格，法线方向一致。重新减面、重拓扑或改变面顺序后，旧的面级 Mask 和 Geometry Recipe 必须作废。

### 4.2 初步硬件档案

| 硬件 | 初步测量 | PoC 外包络 |
| --- | --- | --- |
| 主板 | `40 × 50 × 15 mm` | 每侧增加 `1 mm` 概念间隙 |
| 电池 | `50 × 25 × 15 mm` | 每侧增加 `1 mm` 概念间隙 |
| 扬声器 | `Ø40 × 30 mm` | 径向和深度增加 `1 mm` 概念间隙 |
| 线缆通道 | 未精确测量 | 预留 `8 mm` |

这些数值只用于几何 PoC。进入实物验收前，必须补充 PCB 接口坐标、插头包络、固定孔、线缆出口、弯折半径、电池保护板和不可侵入区。

### 4.3 初步打印工艺档案

当前 `poc-fdm-v1` 使用：

- 后盖外皮：`3.0 mm`；
- 配合间隙：`0.7 mm`；
- 内腔椭球半径：`44 × 42 × 36 mm`；
- 后脑开口半径：`42 mm`；
- 直线装入通道半径：`37 mm`；
- 固定方式：两颗 `M3×35` 螺丝；
- 主体预孔直径：`2.7 mm`；
- 后盖通孔直径：`3.4 mm`；
- 装入路径采样步长：不超过 `1 mm`。

这些参数不是通用常量。更换打印机、材料、喷嘴、层高或固定方式后，必须创建新的 ManufacturingProfile 并重新验收。

## 5. 牛小七开孔流程

```text
输入 STL
  ↓
网格修复、尺度与坐标规范化
  ↓
冻结 HardwareProfile 与 ManufacturingProfile
  ↓
识别正背面、头部、牛角、耳朵、脸和眼睛
  ↓
将语义结果映射为面级 Mask
  ↓
在头部 Mask 内搜索后向候选表面
  ↓
排除保护区并测试包络、壁厚和装入路径
  ↓
生成绑定源模型与档案哈希的 Geometry Recipe
  ↓
确定性几何引擎挖仓、开盖、开功能孔并生成固定结构
  ↓
几何检查 → 切片检查 → 实物装配检查
```

### 5.1 网格规范化

执行以下检查：

- 文件能否解析为有效三角网格；
- 是否封闭；
- 法线绕序是否一致；
- 是否存在自交、非流形边、重复面或零面积面；
- 模型高度、单位和坐标方向是否明确；
- 是否记录源文件 SHA-256、面数和规范化边界框。

修复应发生在语义定位之前。任何会改变拓扑或面顺序的修复都会使旧 Mask 失效。

### 5.2 语义定位与保护区

理想链路使用带相机参数的正面、背面和侧面渲染图：

1. 视觉模型识别正面、背面、头部、牛角、耳朵、脸部和眼睛；
2. 将 2D 语义点或区域通过相机投影和深度缓冲映射到模型表面；
3. P3-SAM 将提示点扩展为连续的三角面实例区域；
4. 系统把视觉标签与实例区域组合成可审查的语义 Mask。

P3-SAM 本身只输出实例部件 ID，不知道“头部”“后脑”或“脸”。多视图语义冲突、投影落点不稳定或置信度不足时，流程必须暂停并要求人工修正锚点。

牛小七的禁止修改区域至少包括：

- 牛角及角根；
- 耳朵及连接区域；
- 脸部和眼睛附近；
- 颈部连接和局部薄弱区域。

### 5.3 后脑候选区域搜索

规划器从头部 Mask 中减去保护区，再根据背面方向筛选法线朝后的连续表面。每个候选区域必须同时通过：

1. **容量检查**：主板、电池、扬声器和线缆包络能够布置；
2. **壁厚检查**：挖空后仍满足 ManufacturingProfile；
3. **维护开口检查**：硬件和托架能够通过开口；
4. **装入路径检查**：从完全抽出到最终安装位置无碰撞；
5. **边界检查**：盖板边界不与牛角、耳朵、脸、眼睛和颈部相交；
6. **固定结构检查**：周边有足够空间生成法兰、螺丝柱和加强筋；
7. **接口检查**：扬声器、麦克风、USB 和按键能连接外界。

如果没有候选同时通过，规划器返回具体失败项，不生成 Geometry Recipe。

### 5.4 选择后盖还是壳体拆分

优先使用维护后盖的条件：

- 所有硬件和托架都能通过单个后部开口；
- 开口周围能够保留可靠法兰和固定结构；
- 内部支撑可以打印或不需要无法取出的支撑；
- 接口可以布置在后盖或邻近区域；
- 装配和维修不要求拆开外观主体。

出现以下情况时，应改为前后壳、上下壳或底座分件：

- 最大硬件无法通过维护开口；
- 增大开口会破坏保护区或剩余壁厚；
- 内部固定件无法安装或需要不可移除支撑；
- 线缆和连接器没有合理装配顺序；
- 后盖固定点会落在薄弱或高曲率区域。

牛小七头部占主体、后脑面积大且可以避开脸部，因此 V1 选择后脑维护盖，而不是将整个角色横向切开。

### 5.5 Geometry Recipe

规划器不直接修改网格，而是输出确定性 Recipe，至少包含：

- Recipe、规划算法和几何执行契约版本；
- 源模型版本、SHA-256、面顺序、单位和坐标系；
- 后盖局部坐标框架：原点、宽度切向、高度切向和外法向；
- 有序曲面边界环及其到源三角面的绑定；
- 空腔、开口、后盖、法兰和装入通道参数；
- HardwareProfile 与 ManufacturingProfile 的版本和内容哈希；
- 主板、电池、扬声器和线缆的相对位置；
- USB、麦克风、扬声器、按键和指示灯孔位；
- 定位结构、托架、螺丝柱和加强筋参数；
- 预期装入方向和装配顺序。

源模型、单位、面顺序、边界环或 Profile 哈希不一致时，几何执行器必须拒绝运行。

### 5.6 确定性几何生成

当前 PoC 使用 Trimesh + Manifold3D 执行真实布尔运算；后续可在保持 Recipe 契约不变的前提下替换为 MeshLib 等几何引擎。

生成结果是两个主要打印零件：

1. **主体**
   - 内部椭球空腔；
   - 后脑维护开口；
   - 开口内侧法兰；
   - 两个主体螺丝柱；
   - 保留的牛小七外观。
2. **后置硬件模块**
   - 从原模型后脑曲面派生的后盖；
   - 扬声器杯；
   - 主板与电池托架；
   - 加强筋；
   - 两个螺钉套筒。

后盖、扬声器杯和托架必须联合成一个连通零件，不能把多个松散托架静默导出。

功能孔独立生成：

- 扬声器使用孔阵列，避免直接删除整个扬声器直径区域；
- 麦克风使用短声道小孔，并尽量与扬声器错开；
- USB 开口要覆盖接口本体、插头外包络和手部操作空间；
- 实物版孔位必须由真实 PCB 坐标重新计算，不能沿用概念坐标。

## 6. 验证与问题修复

### 6.1 几何检查

每次生成后至少检查：

- 主体和后置模块均为封闭网格；
- 主体和后置模块各自只有一个面邻接连通部分；
- 主体与后置模块的非法碰撞体积为 0；
- 硬件与主体的碰撞体积为 0；
- 主板、电池、扬声器之间的碰撞体积为 0；
- 硬件与托架实体不存在非法重叠；
- 装入通道间隙大于 0；
- 完整装入和拆出采样路径无碰撞；
- 配合间隙与最小壁厚满足 ManufacturingProfile。

当前牛小七几何 PoC 的直线装入路径使用不超过 `1 mm` 的离散步长。该结果只能证明已采样位置没有碰撞，不等同于连续碰撞证明。

### 6.2 常见失败与修复顺序

| 失败 | 优先修复 | 禁止做法 |
| --- | --- | --- |
| 正背面或部件识别错误 | 修正多视图、相机或语义锚点，重建 Mask | 让几何引擎猜测语义 |
| 硬件静态包络放不下 | 调整硬件排布、扩大模型或更换硬件 | 直接降低最小壁厚 |
| 放得下但装不进去 | 扩大维护开口、改变装入方向或改为壳体拆分 | 删除相交面冒充通道 |
| 后盖与主体不贴合 | 从同一源曲面和同一边界环派生两侧结构 | 分别手工拟合两个独立轮廓 |
| 布尔失败或结果非流形 | 修复输入、自交和退化面，必要时局部重网格后重算 | 对坏网格继续堆叠布尔 |
| 后置模块出现多个孤立部分 | 增加结构交叠、加强筋或修改联合顺序 | 静默删除小零件 |
| 硬件之间发生碰撞 | 平移、旋转、重排或改变层级和安装顺序 | 侵占电池或连接器安全区 |
| 托架、柱或法兰过薄 | 增厚、加圆角和加强筋，移动固定点 | 依赖切片器自动补强 |
| 内腔需要无法取出的支撑 | 改打印方向、使用斜面/拱顶或增加分件 | 把封闭腔体交给自动支撑 |
| USB、麦克风或扬声器效果不正确 | 使用真实接口坐标、插头包络和声学路径重算 | 仅按外观看起来合理开孔 |

修复后必须重新执行完整链路，不能复用修改前的验证报告。

### 6.3 可打印性检查

可打印性检查分三层，不以单个几何库的“通过”代替全部检查。

#### 几何合法性预检

- 封闭性、流形性和法线；
- 自交、零厚度和退化三角形；
- 最小壁厚、最小孔径和最小结构特征；
- 独立孤岛和异常薄片；
- 主体、后盖与硬件的碰撞和间隙。

#### 打印配置相关检查

- 在选定摆放方向下的悬垂和桥接；
- 内部支撑是否能够生成并移除；
- 后盖、法兰、螺丝柱和托架的受力方向；
- 孔、槽和间隙是否符合材料与打印机的校准结果；
- 零件是否具有稳定接触面；
- 是否存在切片后消失的薄壁或小孔。

#### 切片与预览兜底

必须将主体和后置模块导入目标切片器，确认：

- 无缺层、空路径或异常填充；
- 扬声器孔、麦克风孔和螺丝孔未被合并或封闭；
- 内部支撑可取出；
- 打印时间、材料量和支撑量可接受；
- G-code/路径预览与预期结构一致。

没有目标切片器结果时，状态必须保持 `not_sliced`，不能宣称已经通过完整可打印性检查。

### 6.4 实物装配闭环

建议按以下顺序降低试错成本：

1. 打印配合间隙、螺丝孔和磁铁槽试片；
2. 打印后盖边界与主体开口的局部样片；
3. 使用主板、电池和扬声器假体检查装入顺序；
4. 打印完整主体和后置模块；
5. 装入真实硬件，验证充电、拾音、扬声、按键和指示灯；
6. 多次拆装，检查螺丝柱、法兰、线缆和外壳是否损坏。

最终验收至少要求：能装入、能固定、能闭合、能通电、能交互，并能在不破坏主体的情况下拆出维修。

## 7. 如何适用于其他模型

### 7.1 可以直接复用的能力

- 网格修复、尺度规范化和源版本绑定；
- HardwareProfile 和 ManufacturingProfile；
- 保护区、候选区域和硬约束的概念；
- Geometry Recipe 及其确定性执行方式；
- 空腔、法兰、托架、螺丝柱、磁铁槽和功能孔模板；
- 静态碰撞、装入路径和可打印性检查；
- 切片与实物装配验收流程。

### 7.2 牛小七专用、必须替换的部分

- `+Z` 为正脸、`-Z` 为后脑的固定朝向；
- 头部中心和后脑候选区域的固定坐标；
- 圆形后脑开口与固定椭球空腔；
- 主板、电池和扬声器的固定位置；
- 牛角、耳朵、脸和眼睛的专用启发式 Mask；
- 默认沿后方直线装入；
- 牛小七后脑曲面和两螺丝固定结构。

因此，当前后三个几何节点不能直接用于任意模型。

### 7.3 通用化需要的核心数据结构

建议把牛小七专用参数抽象为六类版本化输入：

1. **ObjectSemanticProfile**
   - 物体类别；
   - 正、背、上、下方向；
   - 部件、保护区和结构关系；
   - 候选维护面；
   - 用户希望保留或允许修改的区域。
2. **HardwareProfile**
   - 硬件包络；
   - 接口面和固定点；
   - 不可侵入区；
   - 线缆和安全间隙。
3. **ManufacturingProfile**
   - 打印机、材料、喷嘴和层高；
   - 最小壁厚、孔径、特征和配合间隙；
   - 悬垂、桥接和支撑规则。
4. **EnclosureTemplate**
   - 后盖、底盖、前后壳、上下壳或抽屉结构；
   - 法兰、螺丝、磁铁、卡扣和定位结构；
   - 支持的装入方向和维护方式。
5. **GeometryRecipe**
   - 绑定源模型、语义结果、两类 Profile 和结构模板；
   - 保存完整局部坐标、边界和几何参数。
6. **ValidationReport**
   - 几何、碰撞、装入路径、打印配置、切片和实物验收状态。

### 7.4 不同模型的结构模板

| 模型类型 | 优先候选区域 | 常用结构 |
| --- | --- | --- |
| 大头人物、动物或 IP | 后脑、背部 | 后盖、背盖 |
| 站立手办 | 背部、底座 | 背盖、底座仓 |
| 方盒或家居产品 | 后面、底面 | 后盖、底盖、抽屉 |
| 车辆或机器人 | 底盘、背板 | 底盘盖、维护舱 |
| 空心摆件 | 底部 | 塞盖、旋转盖、磁吸盖 |
| 入口不足的复杂造型 | 视觉接缝或自然分界 | 前后壳、上下壳或多件装配 |

结构模板只是候选。最终选择仍要由保护区、容量、壁厚、装入路径和打印方向共同决定。

### 7.5 通用候选区域评分

在所有硬约束通过后，可以按以下软指标排序并向用户展示 1～3 个方案：

- 可用内部体积；
- 剩余壁厚裕量；
- 表面曲率和平整程度；
- 对角色正面与标志性特征的影响；
- 维护开口面积和装入便利性；
- 接口可访问性；
- 固定结构可布置空间；
- 打印方向、支撑量和支撑可移除性；
- 接缝的视觉隐蔽程度；
- 重心和结构强度变化。

AI 可以解释和排序候选，但不能绕过硬约束或自由填写未经校验的制造尺寸。

## 8. 通用化后的推荐职责分工

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| 视觉模型 | 物体类别、部件语义、正背方向、保护区建议 | 精确三角面和毫米级几何 |
| P3-SAM | 将提示扩展为面级实例区域 | 部件命名和开盖决策 |
| 几何规划器 | 候选搜索、硬约束判断、参数计算、模板选择 | 直接自由修改网格 |
| 确定性几何引擎 | 布尔、偏移、开孔、法兰、托架和固定结构 | 判断哪个部位适合修改 |
| 验证器与切片器 | 几何、碰撞、装入、打印配置和路径检查 | 替代实物装配测试 |
| 用户/工程师 | 确认外观取舍、维护方式和最终验收 | 手工修补不可追溯结果 |

## 9. 分阶段验收标准

### 阶段 A：牛小七样板

- [ ] 源模型、硬件档案和打印工艺档案均已冻结并有版本哈希；
- [ ] 后脑候选区域不与保护区重叠；
- [ ] 主体和后置模块封闭且各自只有一个连通部分；
- [ ] 硬件、主体和后置模块无非法碰撞；
- [ ] 完整装入与拆出路径通过；
- [ ] 目标切片器检查通过；
- [ ] 实物能够装入、通电、交互和拆出维修。

### 阶段 B：同类大头 IP

- [ ] 不修改牛小七固定坐标即可替换 ObjectSemanticProfile；
- [ ] 系统能够重新识别正背面和保护区；
- [ ] 规划器能生成至少一个合法候选或明确拒绝；
- [ ] 同一 HardwareProfile 和 ManufacturingProfile 可以驱动新 Recipe；
- [ ] 新模型独立完成阶段 A 的全部制造验收。

### 阶段 C：跨类型模型

- [ ] 系统能根据物体类型选择后盖、底盖或壳体拆分模板；
- [ ] 不同模板使用统一 Recipe 和验证契约；
- [ ] 无合法结构时返回可解释失败，不修改源模型；
- [ ] 至少覆盖大头 IP、底座手办和方盒类三组真实样件。

## 10. 当前实现状态与边界

当前已具备：

- 牛小七固定模型的规范化和专用语义启发式；
- 版本化 HardwareProfile、ManufacturingProfile 和 Geometry Recipe；
- Trimesh + Manifold3D 的真实布尔几何；
- 主体与一体化后置硬件模块；
- 静态碰撞、连通性和直线装入采样；
- 独立 P3-SAM ComfyUI 节点，可输出实例部件 ID。

当前尚未完成：

- 视觉模型到 P3-SAM 的通用语义命名闭环；
- 任意模型的 ObjectSemanticProfile 自动生成；
- 通用 EnclosureTemplate 选择器；
- 连续碰撞检测；
- 真实 PCB 接口和线缆模型；
- 自动调用目标切片器；
- 牛小七实物装配和交互验收。

因此，当前准确结论是：**牛小七确定性几何 PoC 已经验证，通用流程已经明确，但任意模型自动适配仍是待实现和待验收能力。**
